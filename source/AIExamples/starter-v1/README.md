AI入门合成示例：12张独立原图、6个采集批次、4类、40个标注和2张已检查的正常样本。图像为本项目自制几何图案（CC0），不含用户业务数据或模型。

1. 配置已有YOLOStudio代码、Python环境和可写AI数据目录，显式连接。点击“准备 / 打开AI示例”，通过原导入与标注服务创建独立项目；重复点击打开已有副本。“新建一份独立示例”才会再建项目。
2. 在数据集页选择图片，进入图片标注，可移动框、修改类别、撤销和保存。全部坐标使用原图像素。
3. 在数据准备页先查看切片预览。预览不生成训练数据；“开始切片处理”的片数进度也不是训练进度。使用示例的批次划分（训练2/3、验证1/6、测试1/6），点击“生成可训练数据集”，原图/批次先划分再切片，防止泄漏。
4. 完成后点击“用于模型训练”，仅将本次data.yaml带入训练页，不替换权重或启动训练。选择已有本地.pt初始权重；没有权重时需由用户自行准备，程序不下载。训练需要现有可用CUDA，未检查CUDA时不代表可用。仅在检查配置后显式点击“开始训练”。
5. 建议学习时使用少量Epoch和batch=1；切换页面不终止任务。“恢复训练”使用原任务有效检查点，与新训练初始权重不同。
6. 训练完成后在测试页显式测试，模型页显式导出ONNX和deployment.json，再应用到检测工程。应用不执行检测。流程节点当前使用ONNX CPU；.pt用于训练/原测试服务，检查点用于恢复，ONNX用于推理部署。

未配置Python时仍可阅读本说明及静态图片。缺少模型或CUDA时不能承诺训练或准确检测。合成例用于学习操作流程，不是工业准确率证明；不能把切片49/49之类进度理解为训练完成。
