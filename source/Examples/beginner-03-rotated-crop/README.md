# 03 旋转裁切：把倾斜区域摆正

## 学习目标
理解旋转中心、顺时针角度和输出尺寸；输出局部坐标可映射回原图。

## 流程
图片 → 旋转裁切 → 图像显示（同时保留原图显示）

## 跟着操作
1. 一键运行，比较原图倾斜面板与裁切后的水平面板。
2. 选旋转裁切节点：中心(160,120)、宽120、高60、角度30°（图像Y向下，正角顺时针）。
3. 查看CroppedImage与CoordinateTransform：变换方向是裁切局部像素中心→原图。
4. 本例通过参数给定位置，不需要模板或模型。已有ROI/Pose输入连接时会覆盖相应几何参数。

## 应看到什么
裁切图120×60；倾斜区域被摆正；坐标矩阵保留30°旋转。

## 动手试一试
把角度30改成0再运行，输出会保留倾斜；改回30可恢复。越界填充按参数执行，预览缩放不参与计算。

所有图片由OpenCV绘制，是自制合成资源。预览上的彩色框是位置示意，不是检测结果；实际输出由原Runtime计算。打开/运行会复制到用户可写工程，内置示例保持只读。修改后在编辑器按F5运行当前副本；回到示例中心再次一键运行会创建新的初始副本。保存后可关闭重开。无需Python、YOLO权重、相机或网络；不含无限/嵌套循环，不代表产线精度认证。
