# 02 矩形裁切：只取需要的区域

## 学习目标
理解左上角X/Y、宽高和原图/裁切局部坐标；原图不会被裁切覆盖。

## 流程
图片 → 矩形裁切 → 图像显示（同时保留原图显示）

## 跟着操作
1. 一键运行后，分别选择“② 查看原图”和“④ 查看裁切后的新图”的Image输出。
2. 选裁切节点，查看左上角(30,30)、宽80、高60；参数单位是原图像素。
3. 点击CoordinateTransform输出，查看OffsetX=30、OffsetY=30；裁切图(0,0)映射回原图(30,30)。
4. 图像窗口1:1/适应/平移只改变显示，不改变上述坐标。

## 应看到什么
裁切图80×60；局部(0,0)对应原图(30,30)，原图仍320×240。

## 动手试一试
把X改成40：输出仍80×60，但局部图会右移。将宽度改为0会提示非法参数；超出原图边界会报错。请在副本中修改。

所有图片由OpenCV绘制，是自制合成资源。预览上的彩色框是位置示意，不是检测结果；实际输出由原Runtime计算。打开/运行会复制到用户可写工程，内置示例保持只读。修改后在编辑器按F5运行当前副本；回到示例中心再次一键运行会创建新的初始副本。保存后可关闭重开。无需Python、YOLO权重、相机或网络；不含无限/嵌套循环，不代表产线精度认证。
