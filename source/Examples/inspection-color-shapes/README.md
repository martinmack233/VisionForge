# 颜色区域 · HSV与全部轮廓

复制并运行。HSV H=0..179，S/V=0..255；绿色范围得到2个区域，红/蓝区域不通过。工作颜色数据不当作BGR显示，Preview是显式还原的显示图。轮廓分析每个目标，保留旋转角度及来源。

所有图片为本平台OpenCV绘制的自制合成资源，不使用业务数据，不依赖YOLO模型，不代表产线准确率。图像坐标x向右/y向下；角度顺时针，最小矩形宽>=高，角度[-90,90)。轮廓面积是边界多边形面积，孔洞单独保留，不等于前景像素数；不是自动扣孔的净面积。

在方案示例中复制后运行；集合面板查看完整结果、选中高亮及局部图像。逐项入口编辑现有子流程；不允许嵌套或副作用节点。工程资源均相对路径。可通过工程包导出/预检/导入到新目录验证重定位。
