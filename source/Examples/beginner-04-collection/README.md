# 04 集合：筛选、排序和选择一项

## 学习目标
理解集合与单项的区别；筛选保留来源，索引从0开始。

## 流程
Blob → 集合 → 筛选 → 排序 → 选择第2项 → ROI → 裁切
筛选集合 → 列表显示 / 数量显示

## 跟着操作
1. 一键运行；原图有3个矩形和1个小点。
2. 查看筛选参数Area≥100，再看排序参数X升序，小点被滤掉。
3. 选“⑫ 看全部筛选结果”，打开“集合/逐项”面板，点击列表行以高亮并查看局部。
4. 索引1是第二项，裁切预览应为30×20。选择单项不会改变原集合。
5. 在集合显示参数中勾选字段、改变颜色/字号，再应用并重新运行。

## 应看到什么
检测4项 → 筛选3项；索引1选中第二个矩形，裁切图30×20。

## 动手试一试
把索引1改成0/2查看第1/3项；改成3会明确越界。把面积下限改为2000会得到空集合，选择节点报错而非沿用旧项。

所有图片由OpenCV绘制，是自制合成资源。预览上的彩色框是位置示意，不是检测结果；实际输出由原Runtime计算。打开/运行会复制到用户可写工程，内置示例保持只读。修改后在编辑器按F5运行当前副本；回到示例中心再次一键运行会创建新的初始副本。保存后可关闭重开。无需Python、YOLO权重、相机或网络；不含无限/嵌套循环，不代表产线精度认证。
