# 01 看懂图像、数字与布尔显示

## 学习目标
区分图像、整数、Boolean端口；知道节点执行成功和业务判断True是两回事。

## 流程
图片 → Blob检测 → 图像显示
目标数量 → 文本显示；数量比较 → 布尔显示

## 跟着操作
1. 点击“一键运行”，软件会创建可写副本。
2. 选“③ 看图像和目标框”，查看Image输出及3个目标框；点击图像输出端口可预览。
3. 选“④ 看数字转文字”和“⑥ 看布尔结果”，查看节点摘要和右侧“执行结果”。
4. 选“⑤ 数量是否等于3”，在参数面板查看比较目标值。图像端口不能直接连接文字端口。

## 应看到什么
目标数量：3；数量等于3：True；原图320×240且有3个目标框。

## 动手试一试
把比较目标值3改成2，应用后重新运行：布尔显示应False，图像与目标数量仍为3。

所有图片由OpenCV绘制，是自制合成资源。预览上的彩色框是位置示意，不是检测结果；实际输出由原Runtime计算。打开/运行会复制到用户可写工程，内置示例保持只读。修改后在编辑器按F5运行当前副本；回到示例中心再次一键运行会创建新的初始副本。保存后可关闭重开。无需Python、YOLO权重、相机或网络；不含无限/嵌套循环，不代表产线精度认证。
