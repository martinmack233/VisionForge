# 05 逐项循环：三个ROI分别检测

## 学习目标
理解当前Item、0基Index、显式共享Image与收集输出；学习查看每次迭代。

## 流程
ROI集合 + 共享原图 → 逐项子流程 → 结果集合 → 列表与叠加显示
子流程：当前项 → ROI → Blob计数 → 比较 → 收集本项结果

## 跟着操作
1. 一键运行，选“④ 查看3次循环的完整结果”，打开右侧“集合/逐项”。
2. 三行依次是索引0/1/2，Number为1/2/3，状态NG/OK/OK；全部节点可以执行成功，同时某项业务NG。
3. 选逐项节点，在参数中点击“编辑逐项子流程”。当前项是本次ROI，Index从0开始，Image是同一张共享原图。
4. 子流程中Blob的ROI线必须来自当前项；IterationOutput明确收集文字、数量、判定和原图ROI。
5. 运行后可在逐项调试下拉框选择某次迭代和中间节点/端口。只保留3次调试，切换/重跑后旧结果失效。

## 应看到什么
完成3项，Complete=True；索引0/1/2分别返回Number=1/2/3、NG/OK/OK。NG项也完成执行。

## 动手试一试
在子流程把比较目标值2改成3，保存子流程后重新运行，预期NG/NG/OK。删除一个ROI后只循环2次。空集合返回0项；执行异常按“停止/记录继续”策略处理，NG不是执行异常。循环有数量预算，不支持无限或嵌套循环。

所有图片由OpenCV绘制，是自制合成资源。预览上的彩色框是位置示意，不是检测结果；实际输出由原Runtime计算。打开/运行会复制到用户可写工程，内置示例保持只读。修改后在编辑器按F5运行当前副本；回到示例中心再次一键运行会创建新的初始副本。保存后可关闭重开。无需Python、YOLO权重、相机或网络；不含无限/嵌套循环，不代表产线精度认证。
