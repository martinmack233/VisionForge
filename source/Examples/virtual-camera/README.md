从本地文件夹采集真实帧，经原模板定位、ROI跟随、Blob检测和OK/NG。

打开或一键运行。首次图像为+10度，下一次为平移/-10度，再下一次无目标；循环回到首帧。第三帧应匹配失败并跳过ROI/Blob，不沿用旧姿态。设备页可从当前节点同步配置，预览与运行分开；运行前停止预览，节点采集下一帧。
