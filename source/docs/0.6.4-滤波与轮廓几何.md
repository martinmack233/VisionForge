# VisionForge 图像滤波与轮廓包围几何

这两个算子来自 0.6.4 算子扩充，已合入以 0.6.3 为基线的公开源码快照。可从当前快照构建运行。工程仍使用 Schema3，工程包仍使用 Version 1。旧版高斯、中值、形态学、提取轮廓、轮廓分析和圆形拟合的节点 ID、参数及连线兼容。历史 0.6.3 下载包缺少本次注册的两个新节点，含这些节点的工程应使用当前快照构建或后续支持它们的版本。

## 从方案示例开始

1. 启动本地交付目录的 `VisionForge.exe`。到「方案示例」，搜索「图像滤波」或「轮廓包围几何」。
2. 点击「一键运行」。示例中心验证内置资源哈希，复制到默认工程目录后调用同一 Runtime 运行。之后可在副本中修改参数，用 F5 重跑。
3. [噪声与方向](../Examples/image-filter-methods/README.md) 里，从输出端口查看各滤波图，双边图另接 Canny。需要比较条纹细节时使用图像视口的 `1:1`。打开 `NeighborhoodSum` 可查看数值平面首行样本。
4. [矩形与圆](../Examples/contour-envelope-geometry/README.md) 里，在示例最后的集合显示节点打开「集合/逐项」，点击行查看原图高亮，可用「查看所选局部」放大。选择最大内接圆节点的 `Collection` 则可检查触边目标和孔洞行的状态及原因。逐项子流程已接好，从筛选后的集合逐项读取直径。

## 图像滤波 `ImageFilter`

工具箱分类「图像预处理」。选择「滤波方式」会显示适用的参数。悬停方式或字段标签可查看含义，应用后运行以生成新结果。

| 方式 | 参数与单位 | 用途与限制 |
| --- | --- | --- |
| 均值（归一化方框） | 核宽、核高分别为 1–255 的正奇数，单位 px | 等权平均轻度随机噪声，边缘会随核增大而变软。 |
| 方框邻域和 | 核宽、核高分别为 1–255 的正奇数，单位 px | 仅 Mono8。输出 `NeighborhoodSum` 的 Float32 数值平面，255×255 核的最大和 16,581,375 可精确表示。 |
| 高斯 | 核大小 1–255 正奇数，Sigma X/Y 单位 px | 复用旧高斯实现。Sigma X=0 根据核计算，Y=0 使用 X 的规则。适合近似高斯噪声。 |
| 中值 | 核大小 1–255 正奇数，单位 px | 复用旧中值实现。适合椒盐或孤立亮暗脉冲。边界固定复制最近像素。 |
| 双边 | 直径 3–31 正奇数；颜色 Sigma 0.01–1000 灰度级；空间 Sigma 0.01–1000 px | 抑制区域内部波动并保留明显边缘。直径与颜色 Sigma 越大，邻域取样及跨边混合可能增加。 |
| 方向平滑 | 取样长度 1–255 正奇数，单位 px；横向或纵向 | 横向在同一行取样，纵向在同一列取样。例如竖条纹沿横向取样可以减弱，同时会平滑横向细节。 |

`Image` 接收 Mono8、RGB8、BGR8。BayerRG8/BayerGB8 需要用已有像素格式转换节点显式转 RGB8/BGR8。彩色均值、高斯、中值及方向平滑按分量处理，双边使用彩色邻域差。正常滤波从 `ProcessedImage` 输出相同像素格式的新图；邻域和只从 `NeighborhoodSum` 输出。切换到邻域和模式时，原图像连线需改接其他图像输出。

可接 `ROI`（`RotatedRectRoi`）或启用参数中的局部滤波 ROI。输入端口优先。范围必须轴对齐、在输入范围内，宽高及相对输入原点的边界为整像素。输出只包含 ROI 自身，不借用框外邻域，也不把框外像素拼接回图像。输出保留坐标空间、局部原点、帧和时间。旋转区域可先显式旋转裁切，再在裁切坐标中滤波。

可选补零、复制、镜像含边或镜像不含边。边界作用于选中的整图或 ROI。分块读共享视图及足量邻域，只写独立输出的有效像素。普通滤波以 512×512 分块，双边保持原行宽并分带，保留 OpenCV 行尾舍入。执行可在块或带之间取消。已有编辑器后台执行和版本校验会丢弃过期结果。

一般范围上限为 1 亿像素，邻域和另限 1600 万像素。双边另限 800 万像素、行宽 65,536 px，且 `像素数 × 直径² × 通道数 ≤ 3 亿`。遇到预算错误时缩小 ROI 或减小直径。图像与数值输出由 Runtime 管理租约。

## 轮廓包围几何 `ContourEnvelope`

工具箱分类「几何测量」。用现有「提取全部轮廓」的 `Collection` 输入。筛选和排序可以放在前后。输入仅接受轮廓集合。Blob 边界框无法提供真实轮廓点或孔洞。

| 方式 | 逐项几何 |
| --- | --- |
| 轴对齐外接矩形 | 左上 `Left/Top`、`Width/Height` 和中心 `X/Y`。宽高采用现有外接像素框约定，输出角度为 0 的矩形 ROI。 |
| 最小面积旋转外接矩形 | 中心、宽高、顺时针角、四角和旋转 ROI。长边作宽，角度在 \[-90°, 90°) 内。WPF 叠加使用四角，Host 也投影四角。 |
| 最小外接圆 | `X/Y/Radius/Diameter`。使用 OpenCV 求圆心，并以原始点的最大距离复核半径。 |
| 最大内接圆（像素近似） | `X/Y/Radius/Diameter`。必须并联接入提取时的同一幅 Mono8 0/255 二值图到 `Mask`。使用树形或两层检索。 |

拟合圆描述轮廓趋势，沿用「圆形拟合」；拟合椭圆沿用「全部轮廓形状分析」。包围几何以像素为单位。需要物理单位时须另行定义并验证标定换算。

内接圆在目标外接框加一圈边界的局部视图中按 8 连通提取当前前景。孔洞、凹口和独立岛会限制计算。整数坐标表示像素中心，背景单元采用以其中心为原点的 1×1 闭方块。L2 距离变换选取前景中心候选，再以到最近背景方块的实际距离定半径。圆可以触及边界，不能进入背景内部。相对连续最优解，中心栅格化和中心距离排序在理想数值下合计引入最多约 1.415 px 的保守半径差；这是栅格近似误差约定，实际光学误差另行评估。测试覆盖矩形、含分离小岛的孔洞及凹形。

触及提取用 ROI 或图像边缘、轮廓经过改变或缺孔洞层级时，内接圆会拒绝受影响的项。孔洞边界在集合中保留，显示为 `HoleBoundary`。不符合原始掩膜缓冲身份、时间帧或坐标时逐项报告。每个目标的局部预算不超过 200 万像素，累计 2000 万像素。空集合输出零项；退化、缺失、超预算等通过 `Status`、`Reason` 和 `Valid` 查看。

- `Collection` 保留逐项状态、几何及轮廓来源键、帧和坐标空间。先以 `Valid=true` 筛选，再按半径、直径或尺寸筛选／排序，避免用 0 代替无效数值。
- `Rectangles` 输出成功的矩形 ROI 集合。用「集合按索引选择」和「当前项转 ROI」连接其他 ROI 节点。索引从 0 开始。
- `Circles` 输出成功的圆集合。可接「集合显示」、选取目标、取字段值或「逐项子流程」。两个几何集合只包含对应类型的有效项。
- `Count` 为输入轮廓数，`ValidCount` 为本次有效几何数。内接圆对一个目标拒绝计算时，同批其他目标仍可检查。

## 命令行

在新发布目录运行以下离线工程。两条命令使用随包资源与同一 Runtime。

```powershell
.\VisionPlatform.Console.exe run .\Examples\image-filter-methods\project.json
.\VisionPlatform.RuntimeHost.exe --project .\Examples\contour-envelope-geometry\project.json --once
```

发布目录的 `ProjectPackages` 下同时提供两份 `.vspkg`，可从 WPF 工程包窗口导入到新目录。合成 PNG 可用 `tools/generate-filter-geometry-examples.py` 和 Pillow 在新目录重新生成，运行软件与打开示例不需要 Pillow。
