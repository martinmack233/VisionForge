# 视构 VisionForge 0.6.3

Windows 11 x64 便携版。完整解压 ZIP 后运行 VisionForge.exe。随包提供 .NET 10.0.15。

从“方案示例 → 从第1课开始”进入五个离线教学案例，练习显示、矩形和旋转裁切、集合筛选选择及逐项循环。

正式构建通过 850 项自动化测试。公开 ZIP 解压后通过 25 个 Console 和 RuntimeHost 离线示例。使用 [SHA256 校验文件](VisionForge-0.6.3-win-x64.zip.sha256)核对公开版 ZIP，验收范围见 [JSON 报告](VisionForge-0.6.3-acceptance.json)。EXE 当前未签名。

## English

Windows 11 x64 portable edition. Extract the full ZIP and start VisionForge.exe. The package includes .NET 10.0.15.

Open Examples → Start with Lesson 1 for five guided offline lessons on display, rectangular and rotated cropping, collection filtering and selection, and per-item iteration.

The build passed 850 automated tests. The extracted public ZIP passed 25 offline Console and RuntimeHost examples. Use the [SHA256 checksum](VisionForge-0.6.3-win-x64.zip.sha256) to verify the public ZIP. See the [JSON report](VisionForge-0.6.3-acceptance.json) for validation scope. The executable is unsigned.
